# TorrentMonitor templates

Этот репозиторий содержит декларативные шаблоны трекеров для [TorrentMonitor Go](https://github.com/lifespirit/TorrentMonitor-go).

Шаблон описывает:

- домены и URL трекера;
- способ проверки авторизации;
- форму Native HTTP-входа;
- признаки правильно загруженной страницы темы;
- извлечение заголовка и времени обновления;
- признаки закрытой раздачи;
- URL и правила загрузки `.torrent`;
- кодировку сайта и значения по умолчанию.

Добавление YAML в этот репозиторий позволяет поддержать новый трекер без изменения Go-кода основного приложения.

## Режимы доступа

Каждый шаблон задаёт рекомендуемый `defaults.access_mode`:

- `native` — прямые HTTP-запросы, минимальная нагрузка и работа без браузера;
- `chromium` — постоянный профиль Chromium, JavaScript, Cloudflare и ручное прохождение CAPTCHA через интерактивную сессию TorrentMonitor.

Пользователь может изменить режим для конкретного трекера в интерфейсе. Сам шаблон остаётся общим для обоих транспортов.

## Использование

В TorrentMonitor укажите источник шаблонов:

```text
https://github.com/lifespirit/TorrentMonitor-templates/archive/refs/heads/main.zip
```

Внешние шаблоны дополняют встроенные. Шаблон с совпадающим `id` переопределяет встроенную версию.

## Создание нового шаблона

1. Скопируйте ближайший по устройству сайта YAML.
2. Назовите файл по основному домену, например `example.org.yaml`.
3. Заполните поля по инструкции [TEMPLATE_FORMAT.md](TEMPLATE_FORMAT.md).
4. Сначала проверьте `native`; выбирайте `chromium` только при реальной необходимости.
5. Проверьте авторизацию, страницу темы, определение обновления и загрузку `.torrent`.
6. Отправьте pull request с одним новым шаблоном и описанием проверенного URL.

## Правила pull request

- не добавляйте логины, пароли, cookies или passkey;
- используйте только положительные признаки успешной страницы;
- не считайте заголовок Cloudflare/CAPTCHA признаком успеха;
- ограничивайте размер загружаемого `.torrent`;
- добавляйте HTML-сигнатуры ошибок в `reject_if_starts_with` или `reject_content_types`;
- указывайте `native` по умолчанию, если сайт работает без браузера.
